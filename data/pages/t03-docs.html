Configuration

Orbit CLI reads its settings from command-line flags, then environment variables, then the orbit.toml file in the project root. Flags always win.

Environment variables

VariableDefaultDescription
ORBIT_API_URLhttps://api.orbit.testBase URL of the Orbit API.
ORBIT_TIMEOUT45Request timeout in seconds.
ORBIT_RETRIES3How many times a failed request is retried.
ORBIT_LOG_LEVELinfoOne of debug, info, warn, error.

Example

ORBIT_TIMEOUT=90 orbit deploy --env staging

Setting a longer timeout is useful for large uploads on slow networks.
